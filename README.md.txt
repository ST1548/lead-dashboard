# LeadMaster Pro - Admin Dashboard

A lightweight, premium admin dashboard that pulls Meta Ad leads directly from a published Google Sheet in real-time.

## Features
- 🚀 **Real-time Data:** Fetches directly from Google Sheets CSV export.
- 📱 **Actionable Contacts:** 1-click calling and WhatsApp integration.
- ✅ **Lead Tracking:** Manual Attended/Missed toggle logic built-in.
- 🎨 **Premium UI:** Styled with Tailwind CSS for a professional look.

## How to Run Locally
Because this app fetches external APIs, it **cannot** be opened directly from your file system (e.g., `file:///C:/index.html`).

1. Open this folder in **VS Code**.
2. Install the **Live Server** extension by Ritwick Dey.
3. Right-click `index.html` and select **"Open with Live Server"**.

## Deployment
This app is 100% static (HTML/CSS/JS) and can be deployed for free on **GitHub Pages**, **Vercel**, or **Netlify**.
